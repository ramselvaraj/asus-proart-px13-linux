# ASUS ProArt PX13 Linux

Community-maintained Linux fixes and small utilities for the ASUS ProArt PX13.

## Available tools

| Tool | What it does |
| --- | --- |
| [Tablet-mode keyboard backlight](tablet-backlight/) | Turns the keyboard backlight off when the PX13 is folded and restores it when unfolded. |
| [Internal microphone fix](microphone-fix/) | Selects the working ALC294 microphone input and prevents excessive hardware boost. |

More PX13-specific tools can be added as separate folders over time.

## Supported hardware

The tools are developed and tested on:

- ASUS ProArt PX13 HN7306WU
- Fedora Linux or Arch Linux with `systemd`

Individual tools may work on other HN7306 variants. Read the tool's own README
before installing it.

## Disclaimer

These are unofficial community tools. They are not provided or supported by
ASUS. Review an installer before running it as root.
